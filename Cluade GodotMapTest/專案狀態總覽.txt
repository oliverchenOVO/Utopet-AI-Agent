■ 使用中的腳本
------------------------------------------------------------------

1. world.gd
   綁定：world.tscn 根節點（World）
   功能：
	 - 時間模擬（sim_clock_minutes，從 06:00 開始，time_speed 可切換）
	 - 讀取所有 Marker2D 位置，分發給各 agent
	 - 每幀呼叫 tick_schedule / tick_stats
	 - 動態加載 5 個子系統
	 - 鍵盤快捷鍵：T P R M S I H F1-F4

2. Jack_Agent.gd
   綁定：Jack 節點（agent_id=0，伐木工）
   排程：06:30 起床 → 07:00 早餐 → 08:00-17:00 伐木輪替
		 → 18:00 晚餐 → 20:00 就寢
   動畫：Cutting Right/Left、臥床用 Idle Front（旋轉 0°）
   生理值：hunger / fatigue / mood_value，tick_stats 每模擬分鐘更新

3. Mike_Agent.gd
   綁定：Mike 節點（agent_id=1，礦工）
   排程：06:30 起床 → 07:00 早餐 → 08:00-17:00 採礦
		 → 18:00 晚餐 → 20:00 就寢
   動畫：Mining Right、臥床用 Idle Front（旋轉 0°）
   備注：礦洞 Marker2D 待建立，工作地點暫以 mike_home 代替

4. Fin_Agent.gd
   綁定：Fin 節點（agent_id=2，釣魚人）
   排程：05:30 起床（早起）→ 06:00 早餐 → 07:00/13:00 釣魚
		 → 18:00 晚餐 → 20:00 就寢
   動畫：Fishing Right、臥床用 Idle Front（旋轉 -90°，向左）

5. Buba_Agent.gd
   綁定：Buba 節點（agent_id=3，農夫）
   排程：06:30 起床 → 07:00 早餐 → 08:00 動物 → 09:00-16:00 澆水耕地輪替
		 → 18:00 晚餐 → 20:00 就寢
   動畫：Sprinkling Right（澆水）/ plowing Right（耕地）/ 臥床用 Idle Front（旋轉 0°）

6. agent_conversation_manager.gd
   動態加載為 ConversationManager
   功能：
	 - 任意兩 Agent 靠近（距離 < 35px）觸發對話
	 - 每對有獨立冷卻時間（60 秒真實時間）
	 - 根據 fatigue / hunger / mood 評估是否互動
	 - 語音泡泡 UI（頭頂彩色氣泡）
	 - 串接 Ollama LLM 生成繁中對話
	 - 對話結束後儲存記憶至 Python API
	 - 信號：conversation_started / conversation_ended / dialogue_line_displayed

7. llm_api_manager_optimized.gd
   動態加載為 ConversationManager 的子節點
   功能：
	 - Ollama 客戶端（port 11434，模型 qwen2.5:7b）
	 - 生成繁體中文雙人對話
	 - 內建 fallback 備用對話（API 不可用時使用）

8. deskpet_manager.gd
   動態加載為 DeskPetManager
   功能：
	 - 浮動可拖曳桌寵面板（永遠置頂）
	 - 右鍵選單：OCR、語音輸入、AI 聊天、新聞摘要、計算機等

9. python_api_client.gd
   由 deskpet_manager 動態載入
   功能：Python FastAPI 客戶端（port 8000）

10. agent_status_panel.gd
	動態加載為 AgentStatusPanel（CanvasLayer layer=20）
	功能：
	  - 右下角 📖 圓形按鈕，點擊展開 / 收起面板
	  - 2×2 格子，每格顯示：
		* SubViewport 鏡像動畫（同步場景角色）
		* 飢餓 / 疲憊 / 心情 三條彩色進度條
	  - 面板右上角有 ✕ 關閉按鈕
	  - 標題：「Agent 狀態面板」

11. conversation_history_ui.gd
	動態加載為 ConversationHistoryUI（CanvasLayer layer=21）
	功能：
	  - 右下角 💬 按鈕（位於 📖 上方）
	  - 列表視圖：每筆對話顯示「AgentA 💬 AgentB」、時間、詳細按鈕
	  - 詳細視圖：聊天室格式，左側彩色頭像，右側氣泡文字
	  - 連續發言邏輯：同一發言者連續說話時，頭像以空白佔位
	  - 即時更新：對話進行中自動追加訊息，自動滾至底部
	  - 面板右上角有 ✕ 關閉按鈕

12. story_generator_ui.gd
	動態加載為 StoryGeneratorUI（CanvasLayer layer=22）
	功能：
	  - 右下角 📚 按鈕（位於 💬 上方）
	  - 點擊後橢圓形面板從按鈕上方滑出，含四個彩色圓形頭像
	  - 點擊圓形頭像 → 顯示該 agent 的今日故事
	  - 20:00 自動觸發生成；手動點擊亦可觸發
	  - 防呆：生成中按鈕顯示 ⏳ 並禁用，完成後恢復
	  - 故事存檔路徑：user://stories/<AgentName>/story_YYYY-MM-DD_HH-MM.txt
		（每次生成新檔案，不覆蓋舊故事）
	  - 面板含 ◀ 返回（回選擇器）與 ✕ 關閉

================================================================
【各 Agent 腳本共用介面】
================================================================

  update_interaction_point(name, pos)   → 登記互動點（world.gd 呼叫）
  tick_schedule(sim_minutes)            → 依時間觸發排程
  tick_stats(sim_minutes)               → 每模擬分鐘更新生理值
  reset_schedule()                      → 新一天重置排程索引
  force_next_schedule()                 → 強制執行下一排程（除錯）
  stop_movement()                       → 立刻停止移動
  on_meal()                             → 用餐：降低飢餓、提升心情
  on_conversation_result(delta)         → 對話結束：調整心情
  get_status() → Dictionary            → 回傳 name/id/mood/hunger/fatigue/...

【外部依賴服務】
================================================================

  Ollama LLM Server
  URL：http://127.0.0.1:11434
  模型：qwen2.5:7b
  用途：NPC 對話生成、故事生成

  Python FastAPI Server
  URL：http://127.0.0.1:8000
  啟動：cd GodotPY && python main.py
  用途：OCR、語音辨識、AI 聊天、新聞摘要、計算機
  記憶 API：POST /memory/context（載入）、POST /memory/save（儲存）
