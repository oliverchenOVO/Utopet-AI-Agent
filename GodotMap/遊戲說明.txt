----------------------------------------------------------------
  按鍵控制
----------------------------------------------------------------

【時間控制】
  T       切換時間速度（循環：1x → 5x → 10x → 30x → 1x）
  P       暫停 / 恢復時間推進
  R       重置時間到 06:00，所有 agent 排程重新開始

【Agent 控制】
  M       開啟 / 關閉 滑鼠點擊移動（預設關閉）
		  開啟後，左鍵點擊地圖可手動指定全部 agent 的移動目標
  S       立刻停止所有 agent 移動

【強制執行排程（除錯用）】
  F1      Jack  → 立即執行下一個排程項目
  F2      Mike  → 立即執行下一個排程項目
  F3      Fin   → 立即執行下一個排程項目
  F4      Buba  → 立即執行下一個排程項目

【資訊顯示（Output 面板）】
  I       顯示世界狀態（時間、速度、各 agent 生理值 / 移動狀態 / 排程進度）
  H       顯示今日完整行程表

================================================================
  右下角 UI 面板（由下到上）
================================================================

📖  Agent 狀態面板
  點擊按鈕開啟 2×2 格子面板。
  每格顯示：
	- 角色名稱與職業圖示（🪓 Jack / ⛏️ Mike / 🎣 Fin / 🌾 Buba）
	- 即時動畫鏡像（同步場景中角色的動作與方向）
	- 🍽️ 飢餓值（紅，越高越餓）
	- 😴 疲憊值（藍，越高越累）
	- 😊 心情值（綠，越高越好）
  面板右上角 ✕ 可關閉。

💬  對話紀錄
  點擊按鈕開啟對話歷史列表。
  列表視圖：
	- 每筆顯示「參與者 💬 參與者」與對話開始時間
	- 點擊「詳細」進入聊天室視圖
  詳細視圖（聊天室格式）：
	- 左側彩色方塊為發言者頭像（J / M / F / B）
	- 同一發言者連續說話時，頭像以空白佔位，形成氣泡連接感
	- 對話進行中會即時追加新訊息，並自動滾至底部
	- ◀ 按鈕返回列表，✕ 按鈕關閉面板

📚  生成故事
  點擊後橢圓形選擇器從按鈕上方滑出，顯示四個彩色角色圓形。
  點擊任一圓形，可閱讀 LLM 為該角色生成的今日小故事。
  生成說明：
	- 遊戲時間到達 20:00 時自動觸發生成（每日一次）
	- 手動點擊 📚 按鈕亦可隨時觸發
	- 生成中按鈕顯示 ⏳ 並禁用，防止重複觸發
	- 四篇故事平行請求，全部完成後恢復按鈕
  故事存檔（不覆蓋，永久保留）：
	user://stories/
	  Jack/story_YYYY-MM-DD_HH-MM.txt
	  Mike/story_YYYY-MM-DD_HH-MM.txt
	  Fin/ story_YYYY-MM-DD_HH-MM.txt
	  Buba/story_YYYY-MM-DD_HH-MM.txt
	（Windows 實際路徑於遊戲啟動時印出於 Output 面板）

================================================================
  Agent 生理值系統
================================================================

  每模擬分鐘更新一次：

  飢餓值（0-100）
	- 隨時間增加（移動中增加較快）
	- 用餐時大幅降低（-75）

  疲憊值（0-100）
	- 移動中增加最快
	- 工作中緩慢增加
	- 睡眠中慢慢恢復（負增長）

  心情值（0-100）
	- 高於 50 時緩慢下降
	- 低於 50 時緩慢回升
	- 用餐 +5，完成對話 +8

  互動觸發判斷：
	疲憊 ≥ 85 → 不互動
	V_social（心情導向）> V_schedule（飢餓 + 疲憊壓力）× 0.55 → 才觸發對話

================================================================
  視覺效果說明
================================================================

【建築遮擋】
  Agent 進入 Buildings 區域時，透明度自動降至 0.5（淡出 0.15 秒）。
  離開後恢復完整透明度（淡入 0.15 秒），模擬角色走進建築內的層級感。

【對話泡泡】
  兩個 Agent 靠近（距離 < 35px）且生理條件允許時，
  頭頂自動出現彩色語音氣泡，每句話顯示約 5 秒。
  每對 Agent 有 60 秒冷卻，不會頻繁重複觸發。
