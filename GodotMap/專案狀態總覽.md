## Agent 日程系統（2026-05-13 全面重構）

### 設計邏輯

```
啟動 / Day 1
  └── 固定用 SCHEDULE_VARIANTS[0]（每角色標準日程）

午夜跨天（Day 2 起）
  ├── 立刻套用「數值 fallback」（保證排程不空）
  └── 非同步發送 POST /schedule/suggest_variant 給 Python 後端
		  ↓ Python 讀取昨天故事 JSON + 查詢人際關係
		  ↓ 組 prompt → 呼叫 qwen2.5:1.5b
		  ↓ 回傳 variant_index（A=0 / B=1 / C=2）
	  若回應在 06:30 前到達 → 更新日程
	  若已來不及（任務已開始）→ 保留數值 fallback
	  若 Python 未啟動 → 保留數值 fallback，遊戲正常運行
```

## Python 後端 API（port 8000）

| 方法 | 路徑 | 功能 | 檔案 |
|------|------|------|------|
| POST | `/social/register` | 註冊 Agent 人格 | social_routes.py |
| POST | `/social/check` | 判斷是否觸發對話 | social_routes.py |
| GET  | `/social/relationship/{a}/{b}` | 查詢兩人關係值 | social_routes.py |
| POST | `/social/complete` | 對話結束更新關係 | social_routes.py |
| POST | `/social/tick` | 推進社交時鐘 | social_routes.py |
| POST | `/memory/save` | 儲存對話記憶 | memory_routes.py |
| GET  | `/memory/context` | 取得記憶摘要 | memory_routes.py |
| **POST** | **`/schedule/suggest_variant`** | **LLM 推薦隔日日程變體** | **schedule_routes.py** |

## 鍵盤快捷鍵

| 按鍵 | 功能 |
|------|------|
| T | 循環切換速度（x1→x2→x5→x10→x30） |
| P | 暫停 / 繼續 |
| R | 重置時間到 06:00，重啟所有 Agent 排程 |
| I | 輸出所有 Agent 當前狀態 |
| H | 輸出今日行程預覽 |
| M | 開關滑鼠點擊移動模式 |
| S | 停止所有 Agent 移動 |
| F1~F4 | 強制 Jack/Mike/Fin/Buba 跳下一個排程 |
